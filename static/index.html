How it works

A sentence,
some knobs.

Try a template ↗
  1. 01

    Write a template.

    A prompt with named slots in it, like {{flow_mode}}. Start from a built-in one, or have the AI draft one from an idea or an image.

  2. 02

    Turn the knobs.

    Every slot becomes a knob with values you choose. Nudge one, hit Randomize, or map them to MIDI.

  3. 03

    Generate or run it.

    Send the sentence to an image model, run the same values through a live sketch, or bring people into The Commons.
