About

Synthograsizer.

A synthesizer for prompts. Write a prompt as a template, put a knob on every part that can change, and turn the knobs to steer an image, a generative sketch, or a live visual. Built for creative people working with creative agents.

Open Synthograsizer ↗GitHub ↗Contact

How it worksTemplate, knobs, output

A template is a sentence with named slots in it, like {{flow_mode}}. Every slot becomes a knob whose values you choose, so a small change to one part of the prompt is one turn of one knob. Randomize, nudge a single knob, or map the knobs to a MIDI or OSC controller and play it like a synthesizer.

Then send the sentence to an image model (Generate), or run the same values through a live p5.js sketch (Run Code). Templates can be written by hand or drafted by the AI from an idea or an image, and they are plain JSON, so they move between every tool in the suite.

The suiteSeven connected tools
  • Synthograsizer: templates, knobs, image generation, live sketches, and Agent Studio with a per-turn trace viewer
  • Glitcher: a pixel-effects studio for images and video
  • Taste Profile: an A/B taste test that builds an agent crew around how you create
  • The Commons: a shared generative canvas with a wall, phone controls and a host's desk
  • ChatRoom: autonomous multi-agent conversations
  • Videorama: prompt to finished video clips (runs locally)
  • Scope plugin: the Glitcher as a Daydream Scope preprocessor

Open source under the MIT license. Recently selected for the Daydream Scope Interactive AI Video Program (Cohort 3).
